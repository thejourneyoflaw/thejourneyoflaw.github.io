第一部分｜今日 AI 观察

今日概念：联邦学习

联邦学习是一种分布式机器学习范式，核心思想是”数据不动模型动”。传统训练要把所有数据汇到中央服务器，而联邦学习让每个参与方在本地用自己的数据训练模型，只把训练后的参数梯度上传到中心做聚合，原始数据始终留在本地。

打个法律人熟悉的比方：这就像多家律所想联合训练一个合同风险识别模型，但谁都不愿把客户合同交给第三方。联邦学习让每家律所在本地用自有合同库训练，只上传”模型参数的更新方向”——这些梯度值本身不含原始合同内容，中心聚合后下发新参数，大家各自更新，循环往复。最终所有参与方共享一个比任何一家单独训练都更强的模型，但没有任何合同离开过各自的服务器。

这个概念之所以值得懂，是因为它直接回应了数据合规的核心焦虑。《个人信息保护法》和《数据安全法》框架下，跨机构数据共享的合规成本极高，而联邦学习在技术层面提供了”可用不可见”的解法。金融行业同理：银行间联合反欺诈建模，无需交换客户交易流水，只交换梯度即可捕捉跨机构的欺诈模式。对法律与金融从业者而言，联邦学习不是技术细节，而是一种合规架构设计工具——它把”数据共享”这个法律难题转化为”参数共享”这个工程问题。

热点一：Claude Duet 发布，Claude 转型主动式智能体

Anthropic 开放 Claude Duet 研究预览版，标志着 Claude 从被动问答助手正式转向主动式智能体。Duet 基于 Claude Opus 5.5 构建，提供独立的 iOS、Android 应用及网页版，核心变化在于 Claude 不再等待用户提问，而是主动推送每日简报、在云端虚拟机中持续执行长周期任务。关键设计在于权限分层：发消息、付款、签字、删除等高风险操作需用户批准后才执行，低风险任务则可自主完成。首批面向美国 Pro 和 Max 订阅用户开放候补名单。

从技术角度看，主动式智能体与被动式聊天的本质区别在于”任务发起权”的归属——Duet 拥有了主动触发执行的权限。云端虚拟机持续运行意味着智能体有了持久化的执行环境，不再受限于单次会话。这对开发者和企业意味着智能体的应用范式从”工具调用”升级为”委托执行”，但权限分层的实现方式也直接决定了安全边界，Duet 的批准机制设计值得关注。

热点二：沃尔玛推出智能体网关，MCP 协议打通交易闭环

沃尔玛正式推出自有智能体网关，即全新 MCP 服务器，让经过审核的 AI 智能体通过模型上下文协议接入平台，可检索线上库存并替用户下单，同时支持沃尔玛和山姆会员店。这是 MCP 协议在零售交易场景的首次大规模商业化落地，意味着 AI 智能体不再只是信息检索工具，而是获得了直接触发交易的权限。

技术上值得关注的是”审核准入”机制——并非任意智能体都能接入，沃尔玛设置了准入门槛。这实际上构建了一个智能体身份认证与授权框架。对行业而言，当电商平台从”服务人类用户”扩展到”服务智能体用户”，传统的用户认证、支付授权、风控模型都需要适配机器主体的行为特征。MCP 协议作为标准化接口，正在成为智能体互联网的 HTTP 层。

热点三：八款个人智能体对比，入口与模型解耦

indigo 发布的八款个人智能体对比显示，大厂把模型、云和订阅打包，开源方案则软件免费、只需付模型和主机费用。核心判断是：入口与模型正在解耦，竞争焦点转向入口、记忆和信任。Personal Agent 提供商被视为智能时代的 Agent OS，应用将以 Agent 形式接入，组成 Agent Internet。

这条洞察的技术含义在于，智能体生态正在复现智能手机时代的”操作系统之争”。当模型能力趋同，差异化来自谁能管理好用户的长期记忆、谁能建立可信的执行环境。对开发者和企业来说，选择哪个智能体平台等同于选择哪个生态绑定的关系。记忆管理和信任机制将成为技术壁垒，这也意味着数据主权问题——智能体掌握的用户记忆数据归属权、可迁移性，将决定用户是否被锁定。

热点四：Vercel 开源 durable-harness，编码智能体崩溃可恢复

Vercel 开源 durable-harness，通过持久日志记录每次模型和工具调用，使编码智能体会话在崩溃或超时后可从新函数恢复。已完成调用从日志读取，不会重复计费。这个项目解决的是智能体执行长任务时的状态持久化问题。

技术关键点在于”持久日志”设计——每次模型调用和工具调用都被序列化记录，恢复时从日志重放，跳过已完成步骤。这本质上是把数据库的 write-ahead log 理念搬到了智能体编排层。对开发者而言，这意味着长周期智能体任务不再因基础设施不稳定而前功尽弃。更深层的意义在于：持久日志天然构成了审计轨迹，每一次模型决策、工具调用都可回溯，这对需要合规审计的场景至关重要。

热点五：howie 谈 Claude Duet 与国内用户无缘

howie.serious 转发 Claude Duet 消息时评论称，这款 personal agent 彻底与国内用户无缘，并调侃它可能口头通知封号。这条看似轻松的评论背后，折射出主动式智能体在跨境数据流动和合规层面的结构性矛盾。

Duet 的核心能力是在云端虚拟机持续执行任务，涉及发消息、付款等操作——这意味着用户数据持续驻留海外服务器，且智能体代理用户执行的操作涉及跨境数据传输。技术上看，主动式智能体比被动式聊天更难合规，因为它不是一次性问答，而是持续性的数据交互流和代理操作流。对国内开发者而言，这提示主动式智能体的合规设计必须前置，而非上线后再补。

第二部分｜每日一个创意 AI 应用深度解析

创意名称：智能体交易签名网关与合规风控中枢

一句话定义： 一套部署在用户与智能体之间的中间层系统，基于 MCP 协议构建交易网关，通过持久日志实现全链路审计，结合联邦学习做跨机构风控，为智能体代理用户的金融与法律操作提供合规护栏与风险兜底。

灵感来源： 本创意直接基于热点一（Claude Duet 主动式智能体）、热点二（沃尔玛 MCP 智能体网关）、热点四（Vercel durable-harness 持久日志）与热点三（八款个人智能体入口与信任之争）组合推演。Claude Duet 证明了智能体可以代理用户执行付款、签字等高风险操作；沃尔玛网关证明了 MCP 协议可以承载真实交易闭环；durable-harness 证明了持久日志可以让智能体操作可回溯、可恢复；而 indigo 的对比则点明信任和记忆是智能体竞争的核心——这四条热点共同构成了”智能体代理交易”的技术可行性边界，也暴露了合规与风控的空白。

为什么现在可行： Claude Duet 的权限分层设计（高风险操作需用户批准）已经提供了”人工确认”的原型；沃尔玛的”审核准入”机制提供了智能体身份认证的实践范例；Vercel durable-harness 的持久日志提供了操作可回溯的技术基础。这三个条件在 2026 年第四季度同时成熟，使得构建一个通用的智能体交易签名网关不再是纸面构想。现实动因是：随着主动式智能体开始代理用户执行金融操作，监管机构和金融机构自身都需要一个可控的中间层。

专业场景怎么用：

法律场景： 律师事务所部署智能体代理处理批量合同签署、文件提交、案件进度跟踪。签名网关拦截所有”签字""提交""删除”类操作，强制弹出人工确认，并自动生成操作审计日志。合规团队可以设定规则：涉及保密协议签署、诉讼文件提交的操作必须经由合伙人二次确认。知识产权场景中，智能体代理监控专利到期日并自动触发续展申请，网关记录每一步决策链路，满足专利代理机构的合规留痕要求。

金融场景： 投研团队让智能体持续监控持仓公司财报异动并自动生成研报更新。风控团队部署网关拦截智能体发起的高风险交易指令——当智能体试图代理用户执行大额赎回、跨账户转账时，网关触发风控规则引擎，强制要求持有人生物识别确认。尽调场景中，智能体代理分析标的公司供应链数据，网关确保所有数据访问行为留痕，满足尽调工作的审计要求。

落地要点展开：

第一，基于 MCP 协议构建智能体交易网关，拦截高风险操作并强制人工确认。技术实现参照沃尔玛网关的准入审核机制，对所有接入的智能体做身份注册与能力声明。网关内设操作分级：只读类操作自动放行，写入类操作记录日志，签名/付款/删除类操作强制人工确认。谁来做法务团队定义操作分级标准，IT 团队实现拦截逻辑。风险在于分级标准过严则智能体失去效率优势，过松则形同虚设，需根据业务场景动态调参。

第二，引入持久日志与崩溃恢复机制，确保智能体操作全链路可审计可回溯。直接采用 Vercel durable-harness 的设计理念，每次模型调用和工具调用写入持久日志，崩溃后可恢复。法律价值在于这份日志天然满足合规审计要求——当监管机构要求说明某笔交易为何发生，日志可完整回溯智能体的决策链路。由基础设施团队负责部署，合规团队负责定义日志保留期限和访问权限。风险在于日志本身包含敏感操作记录，需加密存储并严格管控访问。

第三，部署联邦学习联合风控模型，跨机构共享欺诈特征而不泄露用户数据。多家金融机构通过联邦学习联合训练智能体行为异常检测模型，每家在本地用自有智能体操作数据训练，只上传梯度参数。中心聚合后下发的模型可识别跨机构的智能体欺诈模式——比如同一智能体在 A 机构试探风控规则后在 B 机构执行类似操作。由各机构风控团队联合推进，技术团队负责联邦学习基础设施。风险在于参与方模型质量不均可能影响整体效果，且联邦学习本身不能完全排除梯度反演攻击。

第四，建立智能体操作保险池，为越权操作与资产损失提供风险兜底机制。参照金融行业的保险逻辑，机构按智能体交易量缴纳保费入池，当智能体越权操作导致用户资产损失时，从保险池中赔付。法律团队设计保险条款与免责边界，精算团队建模风险概率。风险在于智能体行为的不确定性远高于人类操作，精算难度大，初期需设较高免赔额。

价值与局限： 这个创意对法律与金融从业者的真实价值在于：当主动式智能体不可避免地开始代理用户执行金融和法律操作时，行业需要一个标准化的合规中间层。签名网关让机构”敢用”智能体，持久日志让监管”敢批”，联邦风控让同行”敢共享”。局限在于：这套体系本身增加了智能体执行的延迟和成本，对高频低额场景可能得不偿失；联邦学习的反演攻击风险虽低但不可忽视；保险池的精算模型在智能体行为数据积累不足的早期阶段，定价可能严重偏离实际风险。在智能体操作模式尚未稳定的过渡期，不应将网关作为唯一风控手段，必须保留人工复核通道。
